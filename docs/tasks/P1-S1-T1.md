## Why this model / review tier
- **Model:** standard scaffolding where every choice is already made in `CLAUDE.md`.
- **Review:** `auto`. It's setup only; the rules docs are reviewed again in P3-S1-T3.

## Context
The public repo `biblekarta` contains only the plan files so far. CI (`.github/workflows/ci.yml`) already calls `pnpm lint`, `pnpm typecheck`, `pnpm test`, `pnpm validate`, `pnpm verify:scripture`, `pnpm build` and `pnpm e2e`, after running `scripts/fetch-scripture.sh`. They must all exist and pass from day one.

The Bible text lives in the private repo `biblekarta-scripture`, which isn't built yet. **Until P1-S3-T5, the site uses `scripture-fixtures/` only.**

## Do this
1. **Astro project.** Create an Astro 5 project, static output, pnpm, Node 22 (`.nvmrc`), with `"packageManager"` set in `package.json`.
   - Add `@astrojs/react` (React 19), TypeScript strict, ESLint (flat config) and Prettier.
   - Add Vitest and Playwright. The README says to run `pnpm exec playwright install chromium` once.
   - Install the runtime deps `zod`, `d3-zoom`, `d3-scale`, `d3-shape`, `d3-selection` and `d3-transition`, plus the dev deps `tsx` and `@types/d3-*`.
2. **Scripts:** `dev`, `build`, `preview`, `lint`, `typecheck` (`astro check && tsc --noEmit`), `test`, `e2e`, `validate` (`tsx src/build/validate-content.ts`) and `verify:scripture` (`tsx src/build/verify-scripture.ts`). The two `src/build/*` files are stubs that print a TODO and exit 0.
3. **`scripts/fetch-scripture.sh`** (stub for now): set `SCRIPTURE_DIR=./scripture-fixtures` and echo "fixtures". P1-S3-T5 replaces it.
4. **`scripture-fixtures/`:**
   - `books-meta.json`: the 66 books with id, scan `name_am`, `name_en`, testament and scan `order_66`, **copied exactly from the PRD appendix table** (Septuagint order: Hos, Amos, Mic, Joel, Obad, Jonah…; 1–2 Pet, 1–3 Jn, Jas, Jude). Ids: gen exo lev num deu jos jdg rut 1sa 2sa 1ki 2ki 1ch 2ch ezr neh est job psa pro ecc sng isa jer lam ezk dan hos amo mic jol oba jon nam hab zep hag zec mal mat mrk luk jhn act rom 1co 2co gal eph php col 1th 2th 1ti 2ti tit phm heb 1pe 2pe 1jn 2jn 3jn jas jud rev.
   - `books/fixture.json`: one clearly labeled **test book** (`"book":"fixture"`, `"name_am":"የሙከራ መጽሐፍ"`), with 2 chapters of short Amharic sentences that are **not scripture** (e.g. "ይህ የሙከራ ጽሑፍ ነው"), stored with spaces only, never ፡.
   - `checksums.json` and `verse-counts.json` for that book.
   - A `README.md`: "Not Bible text. Used only when the private scripture repo is unavailable (forks, local dev without a token)."
5. **`scripture.lock`:** one line, `none`. P1-S3-T5 sets a real commit SHA.
6. **Layout and home page.** `src/layouts/Base.astro` with `<html lang="am">` and a head slot; `src/pages/index.astro` with `<h1>የመጽሐፍ ቅዱስ ካርታ</h1>` and "በግንባታ ላይ".
7. **Folders:** `content/{streams,eras,people,reigns,events,relationships,anchors,sources}/` and `seed/`, each with a `.gitkeep`.
8. **Smoke test.** `e2e/smoke.spec.ts` checks the heading. `playwright.config.ts` has a `webServer` running `pnpm build && pnpm preview --port 4321`, plus desktop (1440×900) and mobile (Pixel 7) projects.
9. **`.gitignore`:** `node_modules`, `dist`, `.astro`, `public/data/`, `.scripture/`, `.env`.

    - Connect the **public** repo.

## Acceptance criteria
- Every CI command runs and exits 0 locally.
- `pnpm build` produces `dist/index.html` with the heading and `lang="am"`.
- `scripture-fixtures/books/fixture.json` contains no ፡ and no text from the Bible.
- `docs/repo-rules.md` contains runnable `gh api` commands for both rulesets.

1. Run `pnpm i && pnpm build && pnpm preview`, then open http://localhost:4321 → you see "የመጽሐፍ ቅዱስ ካርታ".
2. Push the branch → Cloudflare comments a preview URL on the PR (after the `docs/deploy.md` setup) → the same heading appears there.
