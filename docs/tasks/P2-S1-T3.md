## Why this model / review tier
- **Model:** one figure has to serve three uses (in a stream, in the panel, and later in the map) and stay cheap when it's drawn dozens of times.
- **Review:** `auto`.

## Context
- DR-9: a single reusable vector figure in Ethiopian painting style: large almond eyes, flat colour, black outlines.
  - Kinds now: king (crown), queen (crown and veil), prophet (hood, beard, yellow halo).
  - DR-10: figures are decorative (`aria-hidden`); names are always shown as text.
- `design-reference/figure.html` is the approved drawing: a 64×64 viewBox, with parts switched on by kind and a `tone` colour. Copy its paths exactly; don't redraw.
- `Person.figure_kind` also allows `christ`, `apostle` and `other`. **Christ and apostle figures need the church reviewer's approval before release (P5-S1-T2), so don't draw them now.**
- `Person.figure_tone` is optional; the tones are in `tokens.figure` (P2-S1-T1).

## Do this
1. **`FigureSprite.tsx`:** one hidden `<svg>` with a `<symbol>` per kind (`fig-king`, `fig-queen`, `fig-prophet`, `fig-base`).
   - The tone is applied with `fill="var(--fig-tone)"`, so one symbol serves every tone.
   - The chart mounts the sprite once.
2. **`Figure.tsx`:** props `{kind: Person['figure_kind']; tone?: string; size: number}`. No title or text prop: figures carry no text.
   - It renders `<svg aria-hidden="true" focusable="false"><use href="#fig-…"/></svg>` with `--fig-tone` set inline.
   - The default tone is the first figure tone.
   - `christ`, `apostle` and `other` render `fig-base` (no crown, hood, halo or veil), with a `TODO(P5-S1-T2)` comment.
3. **`FigureStandalone.tsx`:** an inline-SVG version, with no sprite needed, for static pages and for panels opened outside the chart.

## Acceptance criteria
- The parts shown per kind match `figure.html`: king = crown + hair + beard; queen = crown + veil, no beard; prophet = hood + halo + light beard.
- Every figure root has `aria-hidden="true"` and contains no text.
- The sprite version and the standalone version produce the same paths for each kind.
- 200 sprite figures render with one `<symbol>` set, not 200 copies of the paths.

## Tests to write or update
- `Figure.test.tsx`: the parts per kind, `aria-hidden`, the tone variable, the fallback for NT kinds, and sprite vs standalone path equality.

## How to test manually
1. Put a king, a queen and a prophet side by side at 120 px → they match `design-reference/figure.html` for each kind.
2. Change the tone → only the robe colour changes.
