## Why this model / review tier
- **Model:** the rules are fully specified by the PRD.
- **Review:** `opus`. This is the first code that changes Bible text automatically, so every rule must be safe and reversible.

## Context
`work/raw/<book>.json` comes from `bk parse`. PRD v5.4's automatic cleaning is **logged and reversible**:
- **Strip** the leading "፤ " artifact (on 17,595 verses).
- **Remove** stray footnote markers: a trailing "a" or "v", `*ፍ1*`, "[see v2]".
- **Move** edition footnotes out of the verse text into a `footnote` field. Examples: "q ቍ@ 30፤ … የግእዝ መጽሐፍ …", and Gen 46:28, where a footnote overwrote the verse (the real verse text is before ‖).
- **Suggest, but never apply,** old-font junk fixes: Latin letters left from legacy-font conversion, mostly in Jeremiah. The usual mapping is KW→ቍ, kW→ኵ, gW→ጕ, D→ጵ, Do→ጶ.
- **Never touch anything else.** Word spacing stays as in the HTML, and ፡ is never added.

## Do this
1. **`tools/bk/clean_core.py`:**
   - One pure function per rule: `strip_leading_artifact`, `remove_stray_markers`, `extract_footnote`. Each returns `(new_text, footnote | None, ops: [{rule, before, after}])`.
   - `suggest_old_font(text) → [{span, suggestion}]`, which returns suggestions only.
   - **Ordering:** apply strip → extract_footnote → remove_stray_markers. Explain why in a comment.
2. **`bk clean`:**
   - Reads `work/raw/` and writes `work/clean/<book>.json` (adds `t`, `footnote`, `suggestions[]`, `rules_applied[]` per verse).
   - Writes `cleaning-log.jsonl` at the repo root, one line per op: `{ref_html, rule, before, after}`. The log is committed, because it's the audit trail.
   - Prints counts per rule. The leading-artifact count must be 17,595; warn otherwise.
3. **`bk clean --verify-reversible`:** rebuild the raw text from `work/clean` plus the log for every verse, and assert equality with `work/raw`. Exit 1 on any mismatch.
4. Rules must be conservative. A marker is only "stray" when it's an isolated Latin `a` or `v` at the end of a verse, or one of the exact patterns listed. When in doubt, leave the text alone and let the flagger flag it.

## Acceptance criteria
- `--verify-reversible` passes on the full Bible.
- The leading-artifact count is 17,595.
- Old-font junk is never auto-replaced, only suggested.
- No rule ever inserts ፡ or changes spacing between words.

## Tests to write or update
- `test_clean.py`: each rule on literal examples from the PRD and the workbook's "Hint" column (Gen 4:26 and Gen 6:22 stray "a", the Gen 46:28 ‖ footnote, a "q ቍ@ 30፤ …" footnote), plus negative cases: a legitimate final letter that isn't a stray marker, and Latin inside old-font junk left untouched. Add a property test that applying the rules and then reversing them is the identity.

## How to test manually
1. Run `uv run --project tools bk clean` → the counts print, including "strip_leading_artifact: 17595".
2. Run `bk clean --verify-reversible` → OK.
3. Open `work/clean/gen.json` and look at 46:28 → `t` is the verse and `footnote` holds the moved note.
