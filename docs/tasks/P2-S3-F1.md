## Why this model / review tier
- **Model:** a small, local layout fix with tests.
- **Review:** `auto`.

## Context
- Follow-up bug found while reviewing P2-S3-T6. The bottom row of the year axis (AxisLayer, `axis-row axis-bottom`) is drawn at `height - BOTTOM_INSET_PX`. `placeLanes` (`geometry.ts`) reserves `AXIS_BAND_PX` above the first lane for the top row but nothing below the last lane, so `height` ends right at the last lane's bottom edge. The Arabic-numeral row is therefore drawn inside the last visible lane.
- Repro: `BK_SEED=1 pnpm dev`, then open `/?y=-898&z=5.97`. The bottom row (910, 900, 890) sits inside the Assyria lane. With `&hide=assyria` it sits inside the Egypt lane.
- This touches files outside the original P2-S2-T4 / P2-S2-T5 file lists, so it is its own task and PR into `phase-2`.

## Do this
1. **`geometry.ts`:** add `AXIS_BOTTOM_PX` (the bottom row's label height plus its inset, plus a small gap). `placeLanes` adds it below the last visible lane, so the SVG height is: top axis band + visible lanes + bottom axis band. It still holds with lanes hidden, and with no visible lanes.
2. **`AxisLayer.tsx`:** keep the bottom row's baseline at `height - BOTTOM_INSET_PX`, which now falls inside the bottom band. Update the comments.
3. **`axis.css`:** update the comment on the bottom row's halo. The row no longer sits over a lane, but the halo still keeps it clear of the grid lines.

## Acceptance criteria
- The bottom row's text sits below the last visible lane's bottom edge and inside the SVG, at every zoom, with any set of lanes hidden (including the last lane, or all of them).
- The bottom row never overlaps the top row.
- Hiding a lane still shifts the SVG height by exactly that lane's height (the `LaneMenu.test.tsx` and `Chart.test.tsx` checks still pass).

## Tests to write or update
- `geometry.test.ts` (new): lane stacking, the bottom band with all lanes shown, some hidden, and none visible; the bottom row fits in the band.
- `AxisLayer.test.tsx`: in the mounted chart, the bottom row sits below the last lane and inside the SVG, also after hiding the last lane and after hiding all lanes.
- `Chart.test.tsx`: the height check includes `AXIS_BOTTOM_PX`.

## How to test manually
1. On the seeded preview, open `/?y=-898&z=5.97`. The Arabic numerals sit below the Assyria lane, on the vellum.
2. Add `&hide=assyria`. The numerals sit below the Egypt lane.
3. Repeat at `z=1` and `z=20`, and with several lanes hidden.
