## Why this model / review tier
- **Model:** a format-fidelity job with formulas, validation and styling.
- **Review:** `auto`. The output is compared against the existing workbook's structure.

## Context
- The proofreaders already use the round-1 format in `tests/fixtures/flagged-verses-v1.xlsx`:
  - **"How to use":** instructions and issue types.
  - **"Summary":** COUNTIF formulas per issue type.
  - **"Flagged verses":** columns `# · Book no. · Book (English) · Book (Amharic, scan name) · Chapter (HTML) · Verse (HTML) · Primary issue · All issues · Hint · HTML text (as received) · Scan reference · Decision · Corrected text (exactly as scan) · Proofreader · Reviewer · Status · Notes`. Only the yellow columns (Scan reference → Notes) are filled in by people.
  - **"Anchor verses":** `# · Anchor · Reference (Amharic) · Reference (English) · What to check · HTML reading (numbers only) · Matches expected? · Scan reading · Confirmed in scan? · Notes`, 31 rows.
- **Keep this format exactly.** Add two sheets.
- Inputs: `work/flags.json`, `rounds/samples/round-N.json`, `work/versification-candidates.json`, `work/clean/` and `scripture/books-meta.json`.

## Do this
1. **`tools/bk/data/anchor_verses.csv`:** copy the 31 anchor/interval rows from the fixture workbook's "Anchor verses" sheet (columns `Anchor` … `Matches expected?`), so later rounds can regenerate the sheet.
2. **`workbook_export.build(round_n, …)`** writes `rounds/round-<N>.xlsx` with:
   - **"How to use":** the fixture's text, plus short sections for the two new sheets and for "Corrected text = words only, separated by single spaces; do NOT type ፡ (it's added automatically). Footnotes go in Notes."
   - **"Summary":** the same formulas, extended with rows for the spot check and versification.
   - **"Flagged verses":** the same columns and order. The yellow fill is on the editable columns; the other columns are locked (sheet protection with no password; it's just a guard). Data validation:
     - **Decision:** `Fix`, `Keep`, `Transcribed`, `Delete marker`, `Split`, `Moved`
     - **Status:** `To do`, `Done`, `Reviewed`
   - **"Anchor verses":** from the CSV, with `Scan reading` and `Confirmed in scan?` as yellow columns.
   - **"Spot check"** (new): the same column layout as "Flagged verses", with Primary issue = `Spot check`. The text is the **cleaned** text (`t`), so the proofreader compares the final form.
   - **"Versification"** (new): one row per candidate chapter, with Book (scan name), Chapter, HTML count, Proposed scan count, Kind, and the yellow `Scan count · Confirmed by · Reviewer · Notes`.
   - Amharic columns in Nyala / Abyssinica SIL, frozen header rows, sensible column widths, wrapped text.
3. **Subsequent rounds.** For round N > 1, include only rows that are still open, plus escalation samples, plus new manual flags.
4. **`bk workbook export --round 1`** prints the row counts per sheet.

## Acceptance criteria
- For round 1, the "Flagged verses" sheet matches the fixture's row set and the non-yellow column values (`#`, Book…HTML text) **cell for cell** (in a test).
- The "Anchor verses" rows equal the fixture's.
- The new sheets exist, with data validation on Decision and Status.
- The file opens in Excel and LibreOffice without repair prompts. Verify by re-reading it with openpyxl, and convert it headlessly with `soffice` if available.

## Tests to write or update
- `test_workbook_export.py`: the cell-for-cell comparison with the fixture for the shared sheets, the presence and validation of the new sheets, and that the round-2 export contains only open rows.

## How to test manually
1. Run `uv run --project tools bk workbook export --round 1`.
2. Open `rounds/round-1.xlsx` in Excel → it looks like your current workbook, with "Spot check" and "Versification" tabs added, and the Decision dropdowns working.
