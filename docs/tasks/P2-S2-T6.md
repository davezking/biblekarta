## Why this model / review tier
- **Model:** level-of-detail rules and label collision handling, within the chart's gesture rule.
- **Review:** `auto`.

## Context
- FR-3: each reign is a segment inside its kingdom's stream, bounded by thin dividers, with the ruler's name and reign years lettered inside.
- FR-4: a reign too short for a label shows only its dividers at the current zoom. The label appears when zoomed in, or in a tooltip on hover or long-press.
- Reign geometry is in the tile: `{reign_id, person_id, stream_id, x0, x1, row, dashed}` per axis (P2-S2-T2). Clip segments to the stream path.
- DR-3: names are lettered in manuscript style (Abyssinica, no bold). Stream names are red ink, body text black. Use `TEXT_ON_FILL` from `tokens.ts` for the label colour on each fill.
- Format years with `formatScholarly` / `formatTraditional` (`dates.ts`) and `createT`.
- Same gesture rule as the axes: text outside the scaled group, labels re-placed imperatively during gestures, and the LOD set recomputed in one commit at gesture end. `ReignLayer` and `LabelLayer` are stubs from P2-S2-T4. Use `ui/Tooltip` (P2-S1-T4).

## Do this
1. **`lod.ts` (pure):** `visibleLabels(items, k, measure)` → the items whose on-screen width `(x1 − x0)·k` fits their measured label plus padding.
   - Higher `importance` wins when labels collide in the same lane.
   - It also returns which items show **name only** and which show **name + years** (years only when both fit).
   - `measure` is injected: canvas `measureText` with the loaded font in the browser (cached per string), and a fixed-width estimate in tests.
2. **`ReignLayer`:** inside the geometry group, the segment fills (clipped to the stream path) and the divider lines (non-scaling stroke). Segments with `dashed: true` get a dashed outline.
3. **`LabelLayer`:** screen-space labels for the LOD-visible reigns and the stream names (stream names in red ink, placed in the visible part of each stream).
4. **Tooltips:** on hover (desktop) or long-press (touch), a reign without a visible label shows a tooltip with its name and years.
5. **Selection:** a hit target ≥ 44 px tall on touch, even for thin segments. Tapping sets the selection in the chart store.

## Acceptance criteria
- At the whole-era zoom, short reigns show only dividers. Zooming in reveals their names, then their years, without overlap.
- Every label colour meets the `TEXT_ON_FILL` contrast pair for its fill.
- Every reign is reachable by hover or long-press tooltip, even without a label.
- No React commits during a simulated gesture; one at gesture end.

## Tests to write or update
- `lod.test.ts`: the fit thresholds, importance priority, name-only vs name + years.
- `ReignLayer.test.tsx`: dividers, clipping, dashed outlines.
- `LabelLayer.test.tsx`: the visible set changes with k, contrast-safe colours, tooltip on long-press.

2. Long-press a thin reign on a phone → a tooltip with its name and years.
