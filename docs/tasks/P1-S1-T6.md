## Why this model / review tier
- **Model:** an off-by-one error here would poison every date on the chart, so it needs careful tests.
- **Review:** `auto`. It's pure, with heavy tests, and the phase review re-checks it.

## Context
The year systems are defined in `CLAUDE.md`:
- traditional AA, with creation = AA 1
- scholarly astronomical years, with 1 BC = 0
- the Ethiopian tradition counts 5,500 years from creation to Christ, so Amete Mihret (AM) = AA − 5500
- Gregorian ≈ AM + 7 or 8 (the year changes in September)

Types come from `src/lib/core/schema.ts`. The label for the traditional axis is still undecided (PRD risk #3), so it must come from i18n.

## Do this
1. Export from `src/lib/core/dates.ts`:
   - `astroToBcAd(y) → {year, era: 'BC'|'AD'}` and `bcAdToAstro(year, era)`
   - `aaToAmeteMihret(aa)`, `ameteMihretToAa(am)`, and `ameteMihretToGregorianRange(am) → [g, g+1]`
   - `formatScholarly(dv, t)`, e.g., "874–853 ዓ.ዓ." / "874–853 BC", "በግምት 966 ዓ.ዓ." / "c. 966 BC", and "30 ዓ.ም." / "AD 30". Certainty adds a prefix for approximate and a suffix for disputed.
   - `formatTraditional(dv, t)`, e.g., "ከፍጥረት 3388". The words come from `t()`.
   - `spanOf(dv) → [start, end]`
   - `isStale(dv, anchorsById)`, which is true when `method === 'derived'` and the anchor's `date.start ≠ anchor_value_used`
   - `t` is a translator function passed in. **Don't import i18n directly**, so this module stays pure.
2. Add the needed keys to `src/i18n/am.json` and `en.json`: `date.bc`, `date.ad`, `date.approx`, `date.disputed`, `axis.traditional.prefix` (value `"ከፍጥረት"`, marked as pending reviewer approval in a `_comment` key), and `date.tbd`.

## Acceptance criteria
- 1 BC ↔ 0, AD 1 ↔ 1, 931 BC ↔ −930.
- AA 5500 → AM 0, and AA 5501 → AM 1.
- The PRD's Genesis results format correctly: the Flood at AA 2256, and Abram's birth at AA 3388.
- No function reads globals, the clock or locale state.

## Tests to write or update
- `dates.test.ts`: the conversions above, each certainty and method in both languages, and the true/false cases of `isStale`.

1. Run `pnpm test dates` → it passes.
