## Why this model / review tier
- **Model:** a linguistic mapping across all the fidel orders, where it's easy to miss a series.
- **Review:** `auto`. It's pure and well tested.

## Context
Search must match Amharic text regardless of homophone fidel variants (FR-25). **This is for search keys only. It's never applied to stored or displayed text.**

## Do this
1. Export `normalizeAm(s)` in `src/lib/core/normalize.ts`. Build the series mapping with code-point arithmetic (series base + order offset 0–7), not a hand-typed list. It:
   1. maps every order of ሐ and ኀ (including the labialized ኈ ኊ ኋ ኌ ኍ) to the matching order of ሀ
   2. maps the ሠ series to ሰ
   3. maps the ዐ series to አ
   4. maps the ፀ series to ጸ
   5. applies a documented, reviewer-editable `LABIALIZED_MAP`, starting with ኍ→ሁ, ቍ→ቁ, ኵ→ኩ, ጕ→ጉ
   6. removes ፡ ። ፣ ፤ ፥ ፦ ፧ ፨ and ASCII punctuation, and collapses whitespace
   7. lowercases Latin text
2. **Do not merge ኸ with ሀ.** They are distinct sounds.
3. Also export `normalizeEn(s)`: lowercase, strip diacritics and punctuation.

## Acceptance criteria
- Each of these pairs normalizes equal: ሐዋርያት = ሀዋርያት, ሠራ = ሰራ, ዐመት = አመት, ጸሎት = ፀሎት, "ዳዊት፡" = "ዳዊት", ዘኍልቍ = ዘሁልቁ.
- ኸ and ሀ stay different.
- Normalizing twice gives the same result as normalizing once.

## Tests to write or update
- The table tests above, plus an idempotence property test over a sample of 200 Ethiopic strings.

## How to test manually
1. Run `pnpm test normalize` → it passes.
2. (After P1-S1-T7) on the playground, typing ሐዋርያት shows the key ሀዋርያት.
