## Why this model / review tier
- **Model:** the chart's architecture: the render/gesture split, the state store and the layer contract that every Sprint 3 task plugs into.
- **Review:** `opus`. Getting the "no React re-render during gestures" rule wrong costs the 60 fps target (NFR, DR-12).

## Context
- `CLAUDE.md`, chart rule: **no React re-render during pan/zoom gestures.** There's one transformed geometry `<g>`, and labels are re-placed on a throttled viewport.
- Architecture §3: four SVG layers, grid → geometry → labels → overlay. Zoom is **horizontal only**.
- Data: `/data/index.json` and `/data/tiles/<era>.json` (types in `src/lib/core/datafiles.ts`, P2-S2-T3). Map years to x only through `timescale.ts`.
- DR-11: on desktop the chart fills the width under a centred title cartouche and toolbar. DR-12: on mobile, the same chart scrolls like a scroll and supports pinch-zoom.
- Phase 1 demo step 9: **production with no content shows only the "under construction" page.** Keep that.
- Sprint 3 tasks fill in the layers and controls in parallel. **This task creates every file they will own as a stub**, already wired in, so they never edit `Chart.tsx`.

## Do this
1. **`src/components/chart/state.ts`:** a tiny external store (subscribe/getSnapshot for `useSyncExternalStore`) holding `{axis, selection, hiddenLanes, committedViewport}`.
   - The live transform is **not** in React state. `committedViewport` is updated only at gesture end, and at most every 150 ms during long inertia.
2. **`zoom.ts`:** d3-zoom bound to the SVG.
   - **Wheel** zooms around the pointer. **Shift + wheel**, horizontal trackpad scroll and one-finger horizontal drag pan. **Pinch** zooms.
   - `touch-action: pan-y`, so a vertical swipe still scrolls the page.
   - The y translate is always 0; set `scaleExtent` and `translateExtent` from the timescale config.
   - During a gesture it sets the `transform` attribute on the geometry `<g>` directly (`scale(k,1)` + translate), and notifies a throttled (rAF) viewport channel that label layers subscribe to **imperatively**.
   - It exposes a `ChartController`: `getView()`, `setView({x, k}, {animate})`, `panToYear(year, axis)` and `focusOn(x0, x1)`. The axis switch, minimap, URL sync and item pages drive the chart only through it, so no later task edits `zoom.ts`.
3. **`Chart.tsx`:** fetches the index and the live era tile through `data/useChartData.ts` (a simple version now; P2-S3-T1 replaces its internals).
   - It renders the four layer groups and mounts `FigureSprite` once.
   - It draws the **stream bands** (from the tile, for the current axis) in the geometry layer, with outlines in black ink and `vector-effect: non-scaling-stroke`.
   - It applies `hiddenLanes` by shifting lane groups (no re-layout).
4. **Layer stubs** in `src/components/chart/layers/`, each rendering `null` with the props it will get (`{tile, axis, cfg, viewport channel}`):
   - `GridLayer`, `AxisLayer` (P2-S2-T5)
   - `ReignLayer`, `LabelLayer` (P2-S2-T6)
   - `ProphetLayer`, `EventLayer`, `FigureLayer` (P2-S3-T2)
   - `AnchorLayer`, `BandLayer` (P2-S3-T3)
   - `OverlayLayer` (selection outline: red, here)
5. **Control stubs** in `src/components/chart/controls/`: `AxisSwitch` (P2-S3-T4), `Minimap` (P2-S3-T5), `LaneMenu` (P2-S3-T6), placed in `Toolbar.tsx` under the title cartouche.
6. **Panel slot:** a stub `PanelSlot.tsx` rendering `null`, given `{selection, tile, index}`, and mounted by `Chart.tsx`. P2-S4-T1 fills it.
7. **Selection:** tapping or clicking a reign or person sets `selection` (the overlay draws a red outline). There's no panel yet (P2-S4-T1).
8. **`src/pages/index.astro`:** if the compiled index has at least one live era, render the title cartouche + toolbar + `<Chart client:load>`; otherwise keep the current "under construction" page.
9. **i18n:** add **all** the chart UI keys Sprint 3 will need, so those tasks don't touch the i18n files:
   - the axis names, as in the Board 5 toolbar: ታሪካዊ ምርምር (scholarly) and ትውፊታዊ (traditional)
   - "N items have no traditional date"
   - the minimap label, "coming soon", the lanes menu label
   - the tradition-only band label, the gap label
   - the chart's `aria-label`

## Acceptance criteria
- On the seeded preview, the Board 5 streams draw on the scholarly axis, and wheel, trackpad, touch pan and pinch work horizontally only.
- **A Vitest test using React's `<Profiler>` sees zero React commits during a simulated 30-event wheel sequence**, and exactly one commit at gesture end.
- The geometry outlines stay 1 px at every zoom (non-scaling stroke).
- A production build with no content serves the "under construction" page and loads no chart JS.
- Every Sprint 3 layer and control, and `PanelSlot`, exists as a wired stub with typed props.
- `ChartController` is the only way other components move the view.

## Tests to write or update
- `state.test.ts`: the store semantics.
- `zoom.test.ts` (happy-dom): y stays 0, the scale extents, and the commit count via Profiler.
- `Chart.test.tsx`: renders the seed tile's streams; hidden lanes shift the groups.
