## Why this model / review tier
- **Model:** state-transition logic over two chronologies, with clear rules.
- **Review:** `auto`.

## Context
- FR-20: the reader chooses the primary axis, scholarly (BC/AD) or Ethiopian traditional (counted from creation).
- Demo step 7: switching to ትውፊታዊ keeps the view in place, and items with no traditional date are **counted, not shown**. Switching back returns to exactly the same view.
- **In the Phase 2 seed every traditional date is TBD**, so on the traditional axis Ahab is one of the counted items. "In place" then means the same calendar year stays centred and the selection is kept.
- Tools you have:
  - `ChartController` (P2-S2-T4) to read and set the view;
  - the chart store (`state.ts`) for `axis` and `selection`;
  - `place()` and `equivalentYear()` from `timescale.ts` (a calendar conversion via `dates.ts`, never a chronology claim);
  - the per-axis unplaced counts in `index.json`;
  - `SegmentedSwitch` (P2-S1-T4).
- The i18n keys (the axis names from the Board 5 toolbar, ታሪካዊ ምርምር / ትውፊታዊ, and the "N items have no traditional date" string) already exist from P2-S2-T4.

## Do this
1. **`axis-switch.ts` (pure):** `nextView({from, to, view, selection, tile, cfg, remembered})` →
   - if `remembered[to]` exists and nothing has moved since leaving it, that exact view (this makes "switch back" exact);
   - otherwise, if the selection has a placed span on `to`, a view centring it at the same zoom;
   - otherwise, the view whose centre is `equivalentYear(centre, from, to)`, at the same zoom.
2. **`AxisSwitch`:** a two-option `SegmentedSwitch` in the toolbar. On change:
   - remember the current view for the old axis, set `axis` in the store, and apply `nextView` through `ChartController` (animated unless reduced motion);
   - show the unplaced count for the new axis next to the switch while it's non-zero (e.g. "23 items have no traditional date").
3. The selection stays selected across switches, even when it is unplaced on the new axis.

## Acceptance criteria
- Scholarly → traditional → scholarly without panning returns exactly the starting view (same x and k).
- With a selection placed on both axes (a test fixture), the switch centres it.
- With the seed, switching to traditional shows the unplaced count, draws no invented positions, and keeps the selection.
- The switch is keyboard-operable, with the current axis exposed (`aria-checked`).

## Tests to write or update
- `axis-switch.test.ts`: all three branches, plus remembered-view invalidation after a pan.
- `AxisSwitch.test.tsx`: the toggle, the count text, keyboard use, no animation under reduced motion.

## How to test manually
1. On the seeded preview, select Ahab and switch to ትውፊታዊ → the count of undated items shows, and Ahab is still selected.
2. Switch back → the chart is exactly where it was.
