## Why this model / review tier
- **Model:** a URL format and a sync loop that must not fight the gesture rule.
- **Review:** `auto`.

## Context
- FR-9: readers can show or hide individual lanes and streams. Demo step 8: hiding a lane moves the lanes below it up. `Chart.tsx` already applies `hiddenLanes` by shifting lane groups (P2-S2-T4).
- FR-10: every chart position and every item has a shareable URL. Architecture §5: `/?y=&z=&ax=s|t&sel=p:<slug>&hide=`. Demo step 9: copy the URL, open it in a new tab → same position, zoom and selection.
- Move the chart only through `ChartController`. The store (`state.ts`) holds `axis`, `selection`, `hiddenLanes` and `committedViewport`.
- `CheckboxMenu` is in `src/components/ui/` (P2-S1-T4). The lanes-menu i18n key exists from P2-S2-T4.
- Item pages (P2-S4-T3) will reuse `viewstate.ts` to open the chart on an item.

## Do this
1. **`src/lib/core/viewstate.ts` (pure):** `parseViewState(search)` and `serializeViewState(state)`:
   - `y` = the centre year on the current axis (integer);
   - `z` = zoom k (2 decimals);
   - `ax` = `s` | `t`;
   - `sel` = `p:<slug>` | `e:<slug>`;
   - `hide` = comma-separated stream slugs.

   Invalid or out-of-range values are dropped one by one (never throw). Serialize omits defaults, so a fresh view has a clean `/`.
2. **`url-sync.ts`:**
   - On load, apply the parsed state (axis first, then the view through `ChartController`, then the selection and hidden lanes).
   - After each **committed** change (gesture end, axis switch, selection, lane toggle), `history.replaceState` the new URL. Never write during a gesture.
   - Selections push a history entry, so Back closes the selection.
3. **`LaneMenu.tsx`:** a `CheckboxMenu` listing the streams in lane order (names in Amharic), toggling `hiddenLanes`. Hiding a lane with a selected item in it clears the selection.
4. **`state.ts`:** add the actions this needs (`toggleLane`, `setSelection`, `hydrate`), with tests.

## Acceptance criteria
- Round trip: `parse(serialize(s))` equals `s` for every valid state, and junk parameters are ignored without errors.
- Opening a copied URL in a new tab restores the axis, centre year (±0.5 year), zoom (±0.01), selection and hidden lanes.
- The URL never changes during a gesture; it changes once at gesture end.
- Hiding Assyria removes its lane and moves the lanes below it up; showing it restores the layout.

## Tests to write or update
- `viewstate.test.ts`: the round trip, defaults omitted, junk dropped, a property test.
- `url-sync.test.ts`: hydrate order, `replaceState` vs `pushState`, no writes during a simulated gesture.
- `LaneMenu.test.tsx` and `state.test.ts`: toggling, and clearing the selection.

## How to test manually
1. On the seeded preview, zoom to 850 BC, select Ahab and hide Assyria. Copy the URL and open it in a new tab → the same view, selection and lanes.
2. Press Back → the selection closes, and the view stays put.
