## Why this model / review tier
- **Model:** project setup plus a table transcribed from given data.
- **Review:** `auto`.

## Context
- This is the **private** repo `biblekarta-scripture`. It already has `CLAUDE.md`, `.github/workflows/` and `tests/fixtures/flagged-verses-v1.xlsx` (round 1 of the proofreading workbook, used later as the test oracle).
- The Society's HTML Bible (`am_new.zip`, WordProject "Selassie" 1954 E.C. text: 66 books, 1,189 chapters, 31,102 verses) goes in `source/am_new.zip`. The owner adds it by hand.
- The HTML uses the **Protestant order and names** (e.g. ሚልክያ, ሰቆቃው, 1ኛ …). The app uses the **scan's order and names**.
- Each later `bk` subcommand lives in its own file in `tools/bk/commands/`, so tasks can run in parallel.

## Do this
1. **Python project.** `tools/pyproject.toml` (uv, Python 3.12, script `bk = "bk.cli:app"`). Deps, added now so later tasks don't edit this file: `typer`, `rich`, `pydantic`, `selectolax`, `openpyxl`, `python-dotenv`, plus the optional extra `ocr = ["google-cloud-vision", "pymupdf"]`. Dev deps: `pytest`, `ruff`.
2. **CLI loader.** `tools/bk/cli.py` is a Typer app that auto-discovers modules in `bk/commands/` exposing `app`.
3. **Config.** `tools/bk/config.py` loads `.env` with `SOURCE_ZIP` (default `source/am_new.zip`), `WORK_DIR` (default `work/`, gitignored), `SCRIPTURE_DIR` (default `scripture/`), `ROUNDS_DIR` (default `rounds/`) and `SCANS_DIR` (the scan PDF, outside git; only for the optional OCR).
4. **`scripture/books-meta.json`**, for the 66 books:
   - `id` (the same ids as the site's `scripture-fixtures/books-meta.json`)
   - scan `name_am` and scan `order_66`, **exactly as in the PRD appendix table**
   - `name_en`, `testament`
   - `html_order` (the Protestant order 1–66)
   - `html_name_am`: leave it `null`. P1-S2-T1 fills it from the HTML.
   - `abbr_am`: `null` until the reviewer approves an abbreviation table.
5. **`tools/bk/books.py`** loads that file and exposes `by_id`, `by_html_order` and `scan_order()`.
6. **`source/README.md`:** "Put am_new.zip here. Never edit it. The scan is the authority; this file is the base text."
7. **`.gitignore`:** `work/`, `.venv`, `__pycache__`, `.env`. **Do commit** `source/am_new.zip` (this repo is private and the file is small) and `rounds/`.

## Acceptance criteria
- `uv run --project tools bk --help` works.
- `books-meta.json` has 66 unique ids. `order_66` and `html_order` are each a permutation of 1..66. Malachi is 39 in both. Hosea, Amos, Micah, Joel are 28, 29, 30, 31 in the scan order, with Joel at 29 in the HTML order.

## Tests to write or update
- `test_books.py`: the count, uniqueness, both permutations, and the order checks above.

## How to test manually
1. Run `uv sync --project tools && uv run --project tools bk --help` → the CLI help appears.
2. Open `scripture/books-meta.json` → ትንቢተ ሚልክያስ is #39 and የያዕቆብ መልእክት is #64.
