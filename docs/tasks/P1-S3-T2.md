## Why this model / review tier
- **Model:** a mechanical font pipeline with known tools.
- **Review:** `auto`.

## Context
- Abyssinica SIL (no bold) is used for manuscript text and verses. Noto Sans Ethiopic (400/600/700) is used for UI controls.
- Both are OFL. They must be **self-hosted and subset** to Ethiopic plus Basic Latin (PRD DR-2), with no Google Fonts at runtime.
- Inks and vellum colors are listed in `CLAUDE.md`. The full token system comes in Phase 2; this task gives the verse viewer what it needs.

## Do this
1. **Source fonts.** Put the TTFs and their OFL licence texts in `fonts-src/`.
2. **Subsetting.** `scripts/subset-fonts.mjs` uses the npm package `subset-font` (a dev dependency; the site repo has no Python), run as `pnpm fonts:subset`, to write WOFF2 files to `public/fonts/`, with unicodes `U+0020-007E,U+00A0,U+1200-137F,U+1380-139F,U+2D80-2DDF,U+AB00-AB2F,U+2013,U+2014,U+2026`.
3. **`src/styles/fonts.css`:** `@font-face` rules with `font-display: swap`, plus `--font-manuscript: 'Abyssinica SIL', 'Noto Serif Ethiopic', serif;` and `--font-ui: 'Noto Sans Ethiopic', sans-serif;`.
4. **`src/styles/base.css`:**
   - `--ink: #1E1712; --ink-red: #8A1A12; --vellum: #E9D8B4`
   - a `.vellum` background: copy the four radial gradients and the inset shadow from the root `div` in `design-reference/board5-desktop.html`
   - `.ms` (manuscript font, `font-weight: 400` forced) and `.ms-red`
5. **`Base.astro`:** import both CSS files and preload the Abyssinica WOFF2.

## Acceptance criteria
- The total WOFF2 payload is ≤ 250 KB.
- No network request goes to fonts.googleapis.com.
- `.ms` text renders in Abyssinica SIL (check the computed style).

## Tests to write or update
- A Vitest test that reads `public/fonts/*.woff2` and asserts the total size is ≤ 250 KB.
- Extend `e2e/smoke.spec.ts` to assert the computed font family of the `h1` includes Abyssinica.

## How to test manually
1. Run `pnpm build && pnpm preview` and open `/`.
2. In devtools → Network, check that the fonts load from `/fonts/` only. The heading is in the Abyssinica calligraphic style on a vellum background.
