## Why this model / review tier
- **Model:** real-world HTML with a known quirk, plus completeness checks.
- **Review:** `auto`. It writes only raw working files, which the count checks verify.

## Context
- The source is `source/am_new.zip`: one HTML file per chapter.
- Verses are marked `<span class="verse" id="N">`. **Quirk:** each chapter's verse-1 marker is inside an HTML comment and must be restored.
- Expected totals: **66 books, 1,189 chapters, 31,102 verses**. The numbering is KJV-style (the HTML's own).
- This step changes no text. Cleaning is the next task.

## Do this
1. **`tools/bk/html_core.py`:**
   - `parse_chapter(html) → [{n, raw}]`, using `selectolax`.
   - Restore the commented verse-1 marker: find `<!-- … <span class="verse" id="1"> … -->` and treat it as a real marker.
   - Take each verse's text up to the next marker.
   - Keep the text **exactly** as in the file, after HTML-entity decoding and NFC normalization only: no trimming inside, no punctuation changes. Collapse only the HTML whitespace that sits between tags.
2. **Book mapping.** Map each file to a book using the zip's folder/file naming and `html_order`. Read each book's HTML title and write it to `books-meta.json` as `html_name_am`. Only touch that field.
3. **`bk parse`:** writes `work/raw/<book>.json` (`{book, chapters: [{n, verses: [{n, raw}]}]}`, HTML numbering) and `work/raw/summary.json` (counts per book), then prints the totals.
4. Fail with a clear message if the totals differ from 66 / 1,189 / 31,102. Empty verses are allowed here (they get flagged later).

## Acceptance criteria
- Running on the real zip prints exactly 66 / 1,189 / 31,102.
- A fixture chapter with the commented verse-1 marker yields verse 1 with the right text.
- `raw` strings are byte-identical to the HTML text content (apart from entity decoding and NFC), checked on fixtures.

## Tests to write or update
- `test_parse.py`: 3 small fixture HTML files in `tools/tests/fixtures/html/`, copied from real chapters including Gen 1, one with an empty verse, and Job 40 with merged numbers. Cover the verse-1 restoration, an empty verse, and the totals logic.

## How to test manually
1. Run `uv run --project tools bk parse` → it prints "66 books · 1189 chapters · 31102 verses".
2. Open `work/raw/gen.json` → Gen 1:1 exists, and still starts with the "፤ " artifact (which is removed in the next task).
